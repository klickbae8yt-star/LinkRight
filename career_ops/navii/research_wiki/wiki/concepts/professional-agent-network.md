# Professional Agent Network

## Description
"Professional Agent Network" is [[Navii]]'s self-applied tagline and core positioning concept: instead of a resume-based labor market, each professional is represented in the market by a personal AI agent (an [[AI Career Agent]]) built from a voice conversation, and each employer is served by agents that generate job descriptions and conduct/summarize candidate conversations. The network framing implies agents on both the supply (job seeker) and demand (employer) side transacting via conversational AI rather than static documents.

Both co-founder [[Saurabh Palan]] and team member [[Aakanksha Upadhyay]] describe themselves on LinkedIn as building "the world's first AI-powered Professional Agent Network," indicating this is the company's primary internal/external framing of its mission, not just marketing copy on the website.
